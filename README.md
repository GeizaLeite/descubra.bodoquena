# Descubra Bodoquena

Este repositório faz parte da atividade de Banco de Dados e Controle de Versão.

## 📊 Banco de Dados

- O arquivo `modelo.sql` contém a criação das tabelas e inserção de dados.
- O arquivo `manipulacoes.sql` contém comandos de manipulação de dados, como SELECT, UPDATE e DELETE.

## 💻 Tecnologias utilizadas

- MySQL
- GitHub (controle de versão)

## ✅ Objetivos

- Criar e modelar um banco de dados relacional.
- Manipular dados com comandos SQL.
- Utilizar controle de versão com Git e GitHub.
